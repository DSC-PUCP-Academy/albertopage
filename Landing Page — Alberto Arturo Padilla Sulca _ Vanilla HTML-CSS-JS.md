# 17. Responsive Design

La página debe funcionar correctamente en:

- Desktop
- Laptop
- Tablet
- Smartphone

Breakpoints recomendados:

```css
@media (max-width: 1024px)
@media (max-width: 768px)
@media (max-width: 480px)
```

En móvil:

- El Hero debe pasar a una sola columna.
- El nombre debe reducir su tamaño.
- Las tarjetas deben apilarse.
- El menú debe convertirse en hamburguesa.
- Las decoraciones deben reducirse.
- Las imágenes no deben desbordarse.

# 24. Criterio final de calidad

Antes de finalizar:

- Verificar que no existan errores en HTML.
- Verificar que CSS cargue correctamente.
- Verificar que JavaScript funcione sin errores.
- Comprobar navegación entre secciones.
- Comprobar responsive.
- Comprobar menú móvil.
- Comprobar que ninguna imagen se deforme.
- Comprobar que ningún elemento genere scroll horizontal.
- Comprobar accesibilidad básica.
- Comprobar que la página pueda ejecutarse simplemente abriendo `index.html`.

La implementación debe quedar lista para ejecutarse localmente sin necesidad de instalar React, Node.js ni dependencias adicionales.
