# Portfolio Personal — Alberto Arturo Padilla Sulca

Landing page personal y portafolio profesional desarrollada para **Alberto Arturo Padilla Sulca**, estudiante de **Ingeniería Informática** en la **Pontificia Universidad Católica del Perú (PUCP)**.

---

## 🎨 Concepto Visual

- **Estilo**: *3D Isometric Blocky Type — Playful Tech Construction Style*.
- **Paleta de Colores**:
  - Fondo: `#F5F4F2`
  - Primarios/Acentos: Azul `#1E5FC4`, Rojo `#E23B2E`, Naranja `#F2941E`, Amarillo `#F5B92E`
  - Neutros: Blanco `#FFFFFF`, Gris claro `#D9D9D9`, Azul acero `#7A93B8`, Texto `#111827`
- **Tipografía**: Google Fonts (*Outfit* / *Poppins*).

---

## 🚀 Tecnologías

- **HTML5** semántico y accesible.
- **CSS3** puro con diseño responsivo, transformaciones 3D e ilustraciones isométricas.
- **JavaScript Vanilla (ES6+)** para interactividad, menú móvil, tilt 3D y animaciones al scroll.
- **Cero dependencias externas**: No requiere React, Vue, Tailwind, Node.js ni paquetes de instalación.

---

## 💻 Instrucciones de Uso

1. Para ver la página, simplemente abre el archivo `index.html` en cualquier navegador moderno (Google Chrome, Microsoft Edge, Mozilla Firefox, Safari).
2. No se requiere ningún servidor de desarrollo ni comando de compilación, aunque también puede servirse con extensiones como *Live Server* de VS Code o `npx serve .`.
